### Задание 2 **(2)**
*Проверьте работу следующей программы на С++*
```
#include <iostream>
int main() {
   {
      int x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   {
      double x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   return 0;
}
```
*Нужны ли в этой программе вложенные фигурные скобки? Дайте подробный ответ с объяснением причин.*

- Да, нужны, фигурные скобки создают область видимости.
- Иначе была бы переменные попали в область видимости main и там была бы ошибка из-за повторного объявления с другим типом.

### Задание 3 **(2)**
*Проверьте работу следующего фрагмента программы на С++.*
```
int s = 0;
for (int i = 0; i < 4; i++) {
   for (int i = 0; i < 3; i++) {
      s += i;
   } 
   s += i; 
}
std::cout << s;
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*
---
![03](03/3s.png)  
![03](03/3se.png)  
- Два разных i - внутреннего и внешнего цикла.
- Внешний цикл выполняется 4 раза (i=0,1,2,3).
- На каждом шаге внутренний цикл добавляет к s сумму 0+1+2=3.
- После внутреннего цикла выполняется s += i уже для внешнего i, 3+i.
- (3+0)+(3+1)+(3+2)+(3+3)=3+4+5+6=18

### Задание 4 **(2)**

*Проверьте работу следующего фрагмента программы на* **Python**.
```
s = 0
for i in range(4):
   for i in range(3):
      s += i
   s += i
print(s)
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*

*На основе этих примеров поясните различия между* **С++** и **Python** *при работе с переменными*.
---
![04](04/4se.png)  
Внутренний цикл 0+1+2=3, последнее значение i это 2, 3+2=5, 5 по 4 раза равно 20.
- В C++ for объявляет новую переменную, которая видна только внутри блока цикла. 
- В Python for не создаёт области видимости.
